Level 3A — Trap Map (Variant 1) · Family Structure

Structure

Question Type

Main Conclusion

Task: Identify the final conclusion that the rest of the argument is built to support.

Stem: "Which one of the following most accurately expresses the main conclusion of the argument?"

Method: Find the support chain. Ask 'Why?'. If another claim supports it, it's a conclusion. If it supports nothing else, it's the main conclusion. (The Why Test)

The #1 Trap

Intermediate Conclusions. A claim that is supported by evidence but also goes on to support the final conclusion.

Question Type

Argument Part

Task: Describe the specific function a particular phrase or sentence serves in the argument.

Stem: "The claim that X plays which one of the following roles in the argument?"

Method: Ask: 'Does it support something?' and 'Is it supported by something?'. Focus on the structural function, not the subject matter.

The #1 Trap

Content vs. Function. Wrong answers often accurately describe the content but misidentify the role (e.g., calling evidence a conclusion).

Level 3A — Trap Map (Variant 1) · Family Patterns & Flaws

Patterns & Flaws

Question Type

Method of Reasoning

Task: Describe the logical technique or strategy the author uses to build their argument.

Stem: "The argument proceeds by"

Method: Abstract the argument into general terms. Identify the premises, conclusion, and how they relate. Match your abstraction to the answer choices.

The #1 Trap

Half-Right Answers. An answer might correctly describe one part of the argument but completely misrepresent another.

Question Type

Parallel Reasoning

Task: Find the answer choice that uses the exact same logical structure as the stimulus.

Stem: "Which one of the following arguments is most similar in its reasoning to the argument above?"

Method: Match the conclusion type (absolute vs. conditional), premise structure, and validity. Strip away the topic.

The #1 Trap

Same Topic, Different Logic. Wrong answers often use the exact same subject matter but completely different logical relationships.

Question Type

Flaw

Task: Identify the specific reasoning error committed in the argument.

Stem: "The reasoning in the argument is most vulnerable to criticism on the grounds that"

Method: Play Devil's Advocate: Ask 'How could the evidence be perfectly true while the conclusion is still completely wrong?'

The #1 Trap

Describing a Flaw Not Committed. The answer describes a real logical fallacy, but not the one that actually occurred in this argument.

Patterns & Flaws

Question Type

Parallel Flaw

Task: Find the answer choice that commits the exact same logical error as the stimulus.

Stem: "The flawed pattern of reasoning in the argument is most similar to that in which one of the following?"

Method: Identify the specific flaw (e.g., conditional logic error, part-to-whole). Match only that specific structural error in the choices.

The #1 Trap

Matching Valid Logic. An answer choice that has the same conclusion type but is actually a valid argument.

Level 3A — Trap Map (Variant 1) · Family Argument Impact & Assumptions

Argument Impact & Assumptions

Question Type

Evaluate

Task: Identify the question or piece of information that would be most helpful in determining if the argument is strong.

Stem: "Which one of the following would it be most helpful to know in order to evaluate the argument?"

Method: Use the Variance Test: Supply opposing extremes (e.g., Yes/No, 0%/100%). If one strengthens and the other weakens, it's the right answer.

The #1 Trap

Irrelevant Context. A question that might be interesting but whose answer doesn't change the validity of the conclusion.

Question Type

Strengthen

Task: Find the new piece of information that makes the conclusion more likely to be true.

Stem: "Which one of the following, if true, most strengthens the argument?"

Method: Identify the conclusion and the evidence. Find the gap. Look for an answer that patches the gap or blocks a potential counterattack.

The #1 Trap

Justifying a Premise. An answer that strengthens a premise that is already accepted as true, rather than strengthening the link to the conclusion.

Question Type

Weaken

Task: Find the new piece of information that makes the conclusion less likely to be true.

Stem: "Which one of the following, if true, most weakens the argument?"

Method: Identify the core argument. Find the gap or assumption. Attack that gap with new evidence that shows why the conclusion doesn't have to follow.

The #1 Trap

Attacking a Premise. You cannot argue with the premises on the LSAT; you can only show they don't necessitate the conclusion.

Level 3A — Trap Map (Variant 1) · Family Argument Impact & Assumptions

Argument Impact & Assumptions

Question Type

Sufficient Assumption

Task: Find the missing premise that, if added, guarantees the conclusion is 100% true.

Stem: "The conclusion follows logically if which one of the following is assumed?"

Method: Look for Dangling Terms (a new concept in the conclusion). Find the Gap (Entry, Middle, End). Insert the answer and rerun the chain.

The #1 Trap

Necessary but not Sufficient. An assumption that must be true for the argument to work, but isn't enough on its own to prove the conclusion.

Question Type

Necessary Assumption

Task: Find a premise that the argument requires or depends upon to work.

Stem: "Which one of the following is an assumption required by the argument?"

Method: Use the Negation Test. Logically negate the answer choice. If the negated version destroys the argument, it is the correct necessary assumption.

The #1 Trap

Sufficient but not Necessary. An answer that would fix the argument perfectly, but goes too far (extreme language) and isn't strictly required.

Level 3A — Trap Map (Variant 1) · Family Principles

Principles

Question Type

Principle Strengthen

Task: Find a broad rule that, if applied, helps justify the specific reasoning in the stimulus.

Stem: "Which one of the following principles, if valid, most helps to justify the reasoning?"

Method: Identify the specific leap made in the argument. Find a generalized rule that bridges that exact gap.

The #1 Trap

Rule is Too Narrow. A rule that applies to the specific topic but doesn't cover the logical jump made.

Question Type

Principle Generalize

Task: Extract the underlying general rule from a specific scenario or argument.

Stem: "Which one of the following generalizations is most clearly illustrated by the situation described?"

Method: Summarize the lesson or moral of the story. Strip away the specific characters and items.

The #1 Trap

Overly Specific Rules. Answers that retain too many details from the original stimulus rather than generalizing.

Question Type

Principle Apply

Task: Take a broad rule and apply it to a new specific situation to see which one fits.

Stem: "Which one of the following judgments most closely conforms to the principle stated above?"

Method: Convert the rule into a strict checklist (sufficient/necessary conditions). One missed necessary condition can eliminate an answer.

The #1 Trap

Reversed Logic. An answer that affirms the consequent or denies the antecedent of the given principle.

Level 3A — Trap Map (Variant 1) · Family Inference

Inference

Question Type

Most Strongly Supported

Task: Find the statement that is best proven by the combination of facts in the stimulus.

Stem: "Which one of the following is most strongly supported by the information above?"

Method: Combine facts. Look for overlaps. The correct answer doesn't have to be 100% proven, but it should be very close based only on the text.

The #1 Trap

Real-World Truths. Statements that are true in the real world but not supported by the specific text provided.

Question Type

Fill in the Blank

Task: Complete the logical thought at the end of the stimulus, usually a conclusion.

Stem: "Which one of the following most logically completes the argument?"

Method: Treat it like a Must Be True or Main Conclusion question depending on the preceding context. Synthesize what was just said.

The #1 Trap

New Directions. An answer that brings up a new, albeit related, point rather than concluding the current line of thought.

Question Type

Must Be True

Task: Find the statement that is 100% guaranteed by the facts in the stimulus.

Stem: "If the statements above are true, which one of the following must also be true?"

Method: Ask: 'Could this possibly be false without contradicting the stimulus?'. Combine absolute statements and conditional chains.

The #1 Trap

Exaggeration. Words like 'all', 'never', 'must', when the stimulus only supported 'some', 'rarely', 'might'.

Level 3A — Trap Map (Variant 1) · Family Inference

Inference

Question Type

Must Be False

Task: Find the statement that completely contradicts the facts in the stimulus.

Stem: "If the statements above are true, which one of the following must be false?"

Method: Use the Coexistence Test. Can this statement and the stimulus both be true at the same time? If no, it's the answer.

The #1 Trap

Could Be False. Statements that might not be true, but aren't strictly proven false by the stimulus.

Level 3A — Trap Map (Variant 1) · Family Paradox / Explain

Paradox / Explain

Question Type

Paradox / Explain

Task: Find the piece of information that resolves a seeming contradiction between two facts.

Stem: "Which one of the following, if true, most helps to resolve the apparent discrepancy?"

Method: Identify both surprising facts. Preserve both facts as true. Find the hidden distinction, bridge, or alternate cause that allows both to coexist.

The #1 Trap

Explaining Only One Side. An answer that explains why one fact is true, but makes the other fact even more confusing.

Level 3A — Trap Map (Variant 1) · Family Dialogue

Dialogue

Question Type

Disagree

Task: Identify the exact point of contention between two speakers.

Stem: "The dialogue provides the most support for the claim that X and Y disagree over whether"

Method: Speaker-by-Speaker Commitment Test. Would Speaker A say 'Yes' or 'No'? Would Speaker B say the opposite? If one speaker has no opinion, it's wrong.

The #1 Trap

Agreeing to Disagree. An issue that both speakers mention, but actually agree on, even if they disagree on the broader conclusion.

Question Type

Agree

Task: Identify a statement that both speakers are committed to believing.

Stem: "The dialogue provides the most support for the claim that X and Y agree that"

Method: Speaker-by-Speaker Commitment Test. Would Speaker A say 'Yes'? Would Speaker B also say 'Yes'?

The #1 Trap

Unstated Opinions. A statement that one speaker clearly agrees with, but the other speaker's stance is completely unknown.
